### Project Description
Our project is a smart expense tracking website that helps users record their daily income and expenses easily. It automatically updates the current balance in real-time and stores all data securely using Firebase. The website also tracks spending categories, mood, and reasons to give better financial awareness.


### The Problem statement
Many students and young individuals struggle to manage their daily expenses and income effectively. They often spend money emotionally, especially during mood swings, stress, boredom, or social pressure leading to poor financial awareness and unplanned overspending. They often make impulsive purchases that later lead to regret and financial imbalance.

There is a need for a smart and simple solution that not only tracks income and expenses but also helps students understand their emotional spending patterns and improve their financial discipline.


### The Solution
We are solving this problem by building a smart expense tracking web application that allows students to record their income and expenses easily in real time. The app dynamically updates the current balance and categorizes each expense based on reason, mood, and category.

By tracking emotional triggers like stress, boredom, or mood swings, the system helps students become more aware of their spending patterns and develop better financial control and decision-making habits.

## Technical Details

### Technologies/Components Used

**For Software:**

* **Languages used:** HTML, CSS, JavaScript
* **Frameworks used:** Firebase (Backend as a Service)
* **Libraries used:** Firebase Authentication, Cloud Firestore
* **Tools used:** Visual Studio Code, Git, Firebase Console, Web Browser (Chrome)

The project uses Firebase for real-time database updates and user authentication, enabling secure login and dynamic balance tracking.


## Features

* **Feature 1: Real-Time Balance Update**
  Automatically updates the user’s current balance whenever income or expenses are added.

* **Feature 2: Emotional Spending Tracking**
  Records mood and reason behind each expense to identify emotional spending patterns.

* **Feature 3: Secure User Authentication**
  Uses Firebase Authentication to ensure that each user’s financial data is private and secure.

* **Feature 4: Categorized Expense Management**
  Allows users to classify expenses by category (Food, Travel, Education, etc.) for better financial analysis and control.
